# Прости меня

Страничка с извинениями: котик, кнопки «Прощаю» и «Нет». С каждым «Нет» котик
плачет всё сильнее — начинается дождь, потом гроза с молниями. Когда нажимают
«Прощаю», тебе прилетает уведомление в Telegram.

## Структура

```
index.html      разметка
style.css       стили, вся анимация завязана на data-level у <body>
script.js       логика уровней грусти + отправка уведомления
image/          фотки котика
api/notify.js   serverless-функция Vercel, шлёт уведомление
```

## Уровни

| Отказов | Фото | Погода |
|---------|------|--------|
| 0–1 | спокойный | ясно |
| 2–3 | со слезинкой | дождь |
| 4–5 | рыдающий | гроза с молниями |

Порядок фоток и погода настраиваются в начале `script.js` — массивы `PHOTOS`
и `WEATHER` (индекс = уровень).

## Уведомления: настройка

Нужен только бот. Три шага, пары минут хватит.

### 1. Завести бота

1. В Telegram написать [@BotFather](https://t.me/BotFather) → `/newbot`
2. Придумать имя, получить токен вида `1234567890:AA...`
3. Открыть чат со своим новым ботом и нажать **Start**

Третий шаг обязателен: пока ты не написал боту первым, Telegram запрещает ему
тебе писать. Заодно по этому сообщению функция и понимает, кому слать.

### 2. Отдать токен функции

Способ попроще — вписать прямо в код. В начале `api/notify.js`:

```js
var FALLBACK_BOT_TOKEN = '1234567890:AAH...';   // токен от BotFather
var FALLBACK_CHAT_ID   = '123456789';           // можно оставить пустым
```

Файл `api/notify.js` выполняется на сервере Vercel, в браузер он не отдаётся —
пользователи страницы токен не увидят. Но если репозиторий на GitHub публичный,
токен увидят все: тогда либо сделай репозиторий Private, либо используй
переменные окружения (ниже). В `script.js` токен не вставлять — этот файл
открыт всем.

### 2-альтернатива. Прописать токен в Vercel

Vercel → проект → **Settings** → **Environment Variables**:

| Ключ | Значение | |
|------|----------|--|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather | обязательно |
| `TELEGRAM_CHAT_ID` | твой id от [@userinfobot](https://t.me/userinfobot) | желательно |
| `NOTIFY_TZ` | `Asia/Almaty` | по желанию |

Без `TELEGRAM_CHAT_ID` тоже работает — функция сама спросит у Telegram, кто
последним писал боту. Но Telegram хранит эти сообщения только сутки, так что
если страницу откроют через неделю после настройки, отправлять станет некуда.
Поэтому id лучше задать явно — это один раз и навсегда.

**Файл `.env` из репозитория Vercel не читает.** Он нужен только для локального
`vercel dev`. На проде переменные живут в настройках проекта.

### 3. Передеплоить

После добавления переменных нужен новый деплой (Deployments → ⋯ → Redeploy),
иначе функция их не увидит.

Вместо телеграма можно указать `DISCORD_WEBHOOK_URL` — уведомление уйдёт в
Discord. Если заданы оба — придёт и туда, и туда.

## Локальный запуск

Просто открыть `index.html` в браузере — страница работает целиком, только
уведомление не уйдёт (в консоли будет «Уведомление не ушло»), потому что
`/api/notify` есть лишь на Vercel.

Чтобы проверить и функцию тоже:

```bash
npm i -g vercel
vercel dev
```

## Проверка, что уведомление работает

1. Открыть задеплоенную страницу, нажать «Прощаю»
2. В консоли браузера (F12) должно быть `Уведомление отправлено`
3. Если нет — Vercel → Deployments → последний → **Functions** → логи `api/notify`

Частые причины молчания:
- не нажат «Start» в чате с ботом → Telegram отвечает `403 bot can't initiate conversation`
- переменные добавлены, но не сделан redeploy
- `TELEGRAM_CHAT_ID` от другого аккаунта

## Защита

- функция принимает только `POST` и только запросы со своего домена
- не чаще одного уведомления в 10 секунд с одного IP
- токены только в переменных окружения, в коде их нет
