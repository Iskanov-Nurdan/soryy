# Прости меня

Страничка с извинениями: котик, кнопки «Прощаю» и «Нет». С каждым «Нет» котик
плачет всё сильнее — начинается дождь, потом гроза с молниями. Когда нажимают
«Прощаю», тебе прилетает уведомление в Telegram.

## Структура

```
index.html      разметка
style.css       стили, вся анимация завязана на data-level у <body>
script.js       логика уровней грусти + отправка уведомления
image/          фотки котика
api/notify.js   serverless-функция Vercel, шлёт уведомление
```

## Уровни

| Отказов | Фото | Погода |
|---------|------|--------|
| 0–1 | спокойный | ясно |
| 2–3 | со слезинкой | дождь |
| 4–5 | рыдающий | гроза с молниями |

Порядок фоток и погода настраиваются в начале `script.js` — массивы `PHOTOS`
и `WEATHER` (индекс = уровень).

## Уведомления: настройка

### 1. Завести бота

1. В Telegram написать [@BotFather](https://t.me/BotFather) → `/newbot`
2. Придумать имя, получить токен вида `1234567890:AA...` — это `TELEGRAM_BOT_TOKEN`
3. Написать [@userinfobot](https://t.me/userinfobot) → он пришлёт твой `Id` — это `TELEGRAM_CHAT_ID`
4. **Обязательно**: открыть чат со своим ботом и нажать «Start», иначе он не сможет тебе писать

### 2. Прописать переменные в Vercel

Vercel → проект → **Settings** → **Environment Variables**, добавить:

| Ключ | Значение |
|------|----------|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | твой id |
| `NOTIFY_TZ` | `Asia/Almaty` (необязательно) |

Список всех переменных — в `.env.example`.

### 3. Передеплоить

После добавления переменных нужен новый деплой (Deployments → ⋯ → Redeploy),
иначе функция их не увидит.

Вместо телеграма можно указать `DISCORD_WEBHOOK_URL` — уведомление уйдёт в
Discord. Если заданы обе — придёт и туда, и туда.

## Локальный запуск

Просто открыть `index.html` в браузере — страница работает целиком, только
уведомление не уйдёт (в консоли будет «Уведомление не ушло»), потому что
`/api/notify` есть лишь на Vercel.

Чтобы проверить и функцию тоже:

```bash
npm i -g vercel
vercel dev
```

## Проверка, что уведомление работает

1. Открыть задеплоенную страницу, нажать «Прощаю»
2. В консоли браузера (F12) должно быть `Уведомление отправлено`
3. Если нет — Vercel → Deployments → последний → **Functions** → логи `api/notify`

Частые причины молчания:
- не нажат «Start» в чате с ботом → Telegram отвечает `403 bot can't initiate conversation`
- переменные добавлены, но не сделан redeploy
- `TELEGRAM_CHAT_ID` от другого аккаунта

## Защита

- функция принимает только `POST` и только запросы со своего домена
- не чаще одного уведомления в 10 секунд с одного IP
- токены только в переменных окружения, в коде их нет
